# IPA phoneme audio attribution

The MP3 files in this directory were selected and renamed from the
[`joshstephenson/PhoneticFlashCards`](https://github.com/joshstephenson/PhoneticFlashCards)
repository at commit `0fb0513d311175564f71bd7fcdca41d54f38f297`.

That project attributes its recordings to Wikimedia's
[IPA vowel chart with audio](https://en.wikipedia.org/wiki/IPA_vowel_chart_with_audio)
and [IPA consonant chart with audio](https://en.wikipedia.org/wiki/IPA_consonant_chart_with_audio).
The recordings are redistributed under the
[Creative Commons Attribution-ShareAlike 3.0 license](https://creativecommons.org/licenses/by-sa/3.0/).

No audio processing was applied in this project; files were only selected and
renamed to stable ASCII asset names. These audio files remain available under
CC BY-SA 3.0. The surrounding application code is not covered by this notice.
