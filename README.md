# 词咔

> 听准每个音，单词一拼就会。

「词咔」是一个面向英语初学者的纯前端学习游戏，把英式音标学习、听音辨音、自然拼读和消消乐练习放在同一个网页中。

## 在线体验

[https://yuanjia01.github.io/word-match-game/](https://yuanjia01.github.io/word-match-game/)

## 核心功能

- 音标学习：44 个英式音标分为 7 课，按「学习 → 听辨 → 消消乐测验」完成闭环练习。
- 单词拼读：点击示例词后逐音素高亮和拼读，最后合成完整英式单词读音。
- 音标消消乐：匹配音标与示例词，点击音标可听音，点击单词可听分段拼读。
- 单词消消乐：支持 3–9 年级和新概念英语词库，内置 3129 个中英文词汇对。
- 自定义单词本：可导入自己的英文单词，并使用自定义词库进行配对练习。
- 学习进度：音标课程和自定义词库保存在当前设备。

## 本地运行

项目无需安装依赖或执行构建。推荐在项目根目录启动一个本地静态服务器：

```bash
python3 -m http.server 8765
```

然后访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。音标教学音频保存在项目内；完整单词的英式录音以及自定义单词的在线翻译需要网络连接。

## 技术说明

- 纯 HTML、CSS 和 JavaScript，无构建依赖。
- 单词朗读优先使用英式语音或在线英式单词录音。
- 单元音使用项目内置 IPA 音频；辅音和双元音使用独立教学音频，避免字母名、尾随元音和双元音断裂。
- 音标学习进度与自定义词库使用 `localStorage` 保存。
- 音频素材许可说明见 `assets/audio/phonemes/NOTICE.md` 和 `assets/audio/teaching/NOTICE.md`。

## 主要数据文件

- `js/data/phonetics.js`：44 个音标、示例词、拼读分段与 7 课课程数据。
- `js/data/words.js`：内置中英文词汇对。
- `js/data/grade-words.js`：3–9 年级词库数据。
- `assets/audio/`：IPA 原始音频与独立教学音频。

## 部署与版本

项目使用 GitHub Pages 发布网页。`main` 分支更新后，Pages 会自动重新部署线上版本。

GitHub Release 用于记录重要版本，可以按语义化版本管理：

- `v1.0.0`：首个正式版本。
- `v1.1.0`：增加新功能，保持现有使用方式。
- `v1.1.1`：修正发音、样式或其他问题。
- `v2.0.0`：有较大产品或使用方式变化的版本。

Release 是代码版本记录，不替代 GitHub Pages 部署。
