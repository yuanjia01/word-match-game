# 单词消消乐（Word Match）

小升初英语单词配对消消乐游戏，单文件纯前端实现，平板/手机/电脑浏览器直接打开即可玩，无需联网。

## 玩法

- 标题下方可选择「全部 / 低年级 / 高年级 / 初中」，切换后会从对应词库重新开始
- 6×3 共 18 个 3D 立体泡泡，每个泡泡上是中文或英文单词
- 点击两个泡泡：中英文互相对应则配对成功，泡泡消失
- 点击英文泡泡会朗读该单词（浏览器内置语音合成）
- 配对成功播放清脆提示音，失败播放低沉提示音
- 全部配对完成显示「恭喜你挑战成功！」和本次用时
- 点「继续挑战」进入下一关，新单词不与之前关卡重复

## 本地游玩

直接双击 `index.html` 用浏览器打开即可（Safari / Chrome 均可，无需联网）。

## 部署到网页（可选）

推送到 GitHub 仓库后，在仓库设置里开启 **GitHub Pages**（Settings → Pages → 分支选择 main 的根目录），即可获得免费网址分享给他人。

## 技术说明

- 纯 HTML + CSS + JavaScript，零依赖、零外部资源
- 单词朗读：Web Speech API（speechSynthesis）
- 提示音效：Web Audio API 实时合成（无需音频文件）
- 内置 252 个词汇，分为低年级 109 个、高年级 70 个、初中 73 个，每关随机抽取 9 个不重复词汇
- 词库维护：中英文配对位于 `index.html` 的 `BASE_WORDS`，分级清单位于 `GRADE_WORDS`
